# LogiLocal

Sistema de apoio à decisão para localização de instalações logísticas, utilizando métodos matemáticos e algoritmos de otimização.

## Funcionalidades

- Cadastro de clientes e demandas.
- Cadastro de instalações candidatas.
- Método do Centro de Gravidade.
- Otimização de rotas com Dijkstra.
- Análise e comparação de custos logísticos.
- Visualização em mapas interativos.

## Tecnologias

Python, Flask, HTML, CSS, JavaScript, SQLite e Leaflet.

## Objetivo

Auxiliar na escolha de localizações estratégicas para centros de distribuição, considerando demanda, distâncias, rotas e custos de transporte.

## Projeto acadêmico

Desenvolvido como trabalho final da disciplina de Logística.
